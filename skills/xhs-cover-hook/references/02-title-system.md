# 标题系统

## 标题目标

封面标题不是文章摘要，而是制造点击理由。

## 推荐结构

### 数字反差

- 4张决赛海报 / 1个母版
- 10分钟 / 做完3版
- 1张参考图 / 做成4张海报

### 方法揭秘

- 系列海报 / 怎么做统一
- 同一个母版 / 怎么换内容
- 这种封面 / 我是怎么做的

### 避坑情绪

- 做系列海报 / 别每张重来
- 我真不该 / 这样做封面
- 这一步错了 / 全部重做

### 结果导向

- 一套视觉系统 / 搞定4张
- 只改3处 / 系列感出来了
- 版式没变 / 每张都新鲜

## 选词规则

优先使用：

- 数字
- 动词
- 结果词
- 冲突词
- 身份词

减少使用：

- 完整长句
- 抽象总结
- “关于、如何进行、方法介绍”等书面词
- 重复表达

## 视觉分配

第一行通常白字，第二行通常黄字。

数字、结果或冲突词应最大。

例如：

第一行白字：4张决赛海报

第二行黄字：1个母版
