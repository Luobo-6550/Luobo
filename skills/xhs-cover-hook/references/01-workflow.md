# 完整工作流

## 阶段 1：材料接收

识别用户是否提供：

- 选题或文章标题
- 人物照片
- 作品、界面或结果图
- 风格参考
- 明确尺寸

不要求材料全部齐全才能开始。

## 阶段 2：内容钩子

将选题压缩为一个点击理由，优先考虑：

1. 数字反差
2. 一种方法解决多个结果
3. 低成本或短时间
4. 失败、后悔或避坑
5. 方法揭秘
6. 身份冲突
7. 前后变化

## 阶段 3：标题收敛

先给 3 个标题方向，再根据用户反馈继续减少字数。

标题收敛顺序：

完整文章标题 → 主题短句 → 结果/冲突 → 两行视觉标题

例如：

“世界杯决赛海报怎么做到统一又不重复”

可以收敛为：

“4张决赛海报 / 1个母版”

## 阶段 4：人物重塑

人物照片作为身份锚点，不是固定素材。

根据标题设计：

- 表情
- 手势
- 动作
- 服装
- 构图
- 光线

人物动作必须能解释标题，而不是单纯站着。

## 阶段 5：证据选择

只选择最能证明标题的一张图。

标题讲“1个母版”，作品证据就应该展示代表性母版或其中一张完成作品，并让人物用“1”手势强化。

## 阶段 6：视觉层级

阅读顺序通常为：

1. 黄色或白色核心标题
2. 人物脸与表情
3. 作品或界面
4. 一个小标签

## 阶段 7：确认与生成

确认项不超过：

- 标题
- 人物动作
- 核心证据

其余视觉细节可由技能自行判断。

## 阶段 8：复盘

生成后优先检查：

1. 字是否太多
2. 人物是否像本人
3. 动作是否与标题对应
4. 作品是否清楚
5. 画面是否过满
