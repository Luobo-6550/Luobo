# 生图提示词模板

在用户确认后，按下面结构编写生成提示词。

## 任务

生成一张 3:4 小红书知识类封面，主题为【主题】。

## 人物身份

使用用户上传的人像作为脸部身份参考。不要机械抠出原照片；重新设计更适合封面的半身人物，保持脸部辨识度。

人物设定：

- 表情：【震惊 / 得意 / 疑惑 / 后悔 / 思考】
- 动作：【手势或与作品互动】
- 服装：【服装】
- 位置：【左 / 右 / 中下部】

## 核心作品证据

使用用户上传的【作品或界面】作为唯一核心证据。

展示方式：【手持 / 倾斜卡片 / 电脑屏幕 / 手机界面】。

保持作品内容清晰，但不要压过主标题。

## 标题

只保留两行：

- 第一行白字：【第一行】
- 第二行黄色大字：【第二行】

第二行比第一行更大。标题使用粗黑字、黑色描边、硬投影和轻微颗粒质感，手机端清晰可读。

## 小标签

只保留一个：【标签】。

使用黄色贴纸或黄底黑字。

## 背景与风格

- 深色、高对比背景
- 与主题相关的轻量场景氛围
- 少量箭头、强调线或贴纸元素
- 不添加长文案、卖点列表或多个横幅
- 整体像高点击小红书知识封面，而不是信息海报或 PPT

## 输出要求

- 3:4 竖版
- 标题正确且清晰
- 人物脸部身份稳定
- 作品证据明确
- 信息简洁
